Download Template

Use this template to prepare your data before uploading. All 15 indicators are pre-configured with correct headers.

File Format Guide
  • First row must be the header row (use the template)
  • Reading Date column: YYYY-MM-DD format
  • Station Name must match an existing station exactly
  • Blank cells are accepted — indicator will be recorded as not measured
  • Compliance is auto-calculated against SANS 241:2015 standards
  • Re-uploading the same station + date updates existing measurements
